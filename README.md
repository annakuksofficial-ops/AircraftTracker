# AircraftTracker

## Описание
Программа для отслеживания самолётов в воздушном пространстве 
выбранной страны с использованием внешних API

## Функциональность
- Получение географических координат через Nominatim API
- Получение информации о самолётах через OpenSky API
- Сохранение данных в JSON файл
- Фильтрация самолётов по стране регистрации
- Фильтрация самолётов по диапазону высот
- Вывод топ-N самолётов по высоте
- Сортировка по скорости

## Установка и запуск

### Требования
- Python 3.12+
- Установленные зависимости из requirements.txt

### Установка зависимостей
pip install -r requirements.txt

## Запуск программы
python main.py

## Тестирование
pytest tests/ -v --cov=src
